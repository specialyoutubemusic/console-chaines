Privacy Policy

Channel Production Console · Last updated: October 8, 2026

Scope

Channel Production Console is a private tool used only by the owner of the YouTube channels it manages. It runs on the owner's own computer. It is not a public service and has no other users.

YouTube API Services

The tool uses YouTube API Services. Use of the tool is subject to the YouTube Terms of Service and the Google Privacy Policy.

Data accessed

With the owner's authorization, the tool requests these Google OAuth scopes:

  • youtube.force-ssl and youtube.readonly: read and update the owner's own videos (title, description, tags, category, language, thumbnail, privacy status and scheduled publish time, altered content and audience declarations).
  • yt-analytics.readonly and yt-analytics-monetary.readonly: read the analytics and revenue reports of the owner's own channels.

How data is used and stored

  • Data is used only to manage and measure the owner's own channels.
  • OAuth tokens, video metadata and analytics are stored locally on the owner's computer. Nothing is sent to any server other than Google's.
  • No data is sold, shared with third parties, or used for advertising.
  • No data about viewers or other YouTube users is collected beyond the aggregated analytics YouTube provides to channel owners.

Retention and deletion

Stored data is kept only as long as it is needed to manage the channels, and analytics copies are refreshed regularly. Deleting the tool's local folder removes all stored data and tokens.

Revoking access

Access can be revoked at any time from the Google security settings page: https://myaccount.google.com/permissions. Once revoked, the tool can no longer read or change anything.
